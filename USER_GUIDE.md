# 📖 Guida Utente - Estetica Digitale

Benvenuto su **Estetica Digitale**, una piattaforma di publishing digitale moderna per condividere articoli sulla bellezza e l'estetica nel mondo digitale.

## 🔐 Accesso e Registrazione

### Come Registrarsi

1. Clicca il bottone **"Accedi"** in alto a destra
2. Scegli uno dei metodi di login:
   - **Google**: Accedi con il tuo account Google
   - **GitHub**: Accedi con il tuo account GitHub
   - **Email**: (Implementazione futura)

3. Una volta autenticato, il tuo profilo sarà creato automaticamente
4. Verrai reindirizzato alla home page

### Il Tuo Profilo

- Clicca sull'avatar in alto a destra
- Seleziona **"Profilo"** dal dropdown menu
- Visualizza i tuoi articoli
- Clicca **"Modifica profilo"** per aggiornare:
  - Username
  - Biografia personale
  - Avatar

## ✍️ Scrivere Articoli

### Avvia un Nuovo Articolo

1. Clicca il bottone **"Scrivi"** nella navbar (solo se autenticato)
2. Vedrai il form di editor con i seguenti campi:

### 1. Titolo
- Inserisci un titolo accattivante
- Apparirà grande e con font serif elegante
- Campo obbligatorio

### 2. Descrizione (Excerpt)
- Scrivi una breve descrizione dell'articolo
- Apparirà nelle anteprime sulla home page
- Max 2-3 righe consigliato

### 3. Immagine di Copertina
- Clicca nell'area tratteggiata per caricare
- Formati supportati: JPG, PNG, WebP
- Apparirà nell'anteprima e all'inizio dell'articolo
- Optional ma consigliato

### 4. Contenuto (Editor)
- Usa l'editor Tiptap per scrivere il tuo articolo
- **Toolbar disponibili**:
  - **B** / *I* : Bold / Italic
  - ~~S~~ : Strikethrough
  - **H2** / **H3** : Heading 2 / Heading 3
  - 📰 : Blockquote
  - `code` : Inline code
  - • : Bullet list
  - 1. : Numbered list
  - 🔗 : Aggiungi link
  - 🖼️ : Inserisci immagine
  - ✕ : Cancella formattazione

### 5. Tag
- Inserisci tag separati da virgola
- Es: "design, estetica, digitale"
- Appariranno come chip colorate
- Aiutano i lettori a trovare il tuo articolo

### 6. Pubblica o Salva come Bozza
- **Salva come Bozza**: L'articolo non sarà visibile pubblicamente
- **Pubblica**: L'articolo sarà visibile su home page e ricercabile

## 📰 Leggere Articoli

### Home Page
1. Scorri la griglia di articoli
2. Ogni card mostra:
   - Immagine di copertina
   - Titolo
   - Descrizione breve
   - Avatar e nome autore
   - Data di pubblicazione
   - Tag
   - Numero di like

### Filtrare per Tag
1. Usa la barra di tag sotto il titolo "Estetica Digitale"
2. Clicca su un tag per filtrare
3. Clicca di nuovo per deselezionare
4. Combina più tag per filtri complessi

### Leggere un Articolo Completo
1. Clicca su una card articolo
2. Visualizzerai:
   - Titolo grande
   - Immagine di copertina
   - Informazioni autore
   - Contenuto formattato
   - Numero di like

### Azioni su Articolo
- **❤️ Like**: Clicca il cuore per aggiungere un like
  - Sono necessari per usare questa funzione: accedi prima
  - Il conteggio si aggiorna in tempo reale
- **Modifica** (solo autore): Correggi l'articolo
- **Elimina** (solo autore): Rimuovi l'articolo

## 👤 Il Tuo Profilo

### Visualizzare il Profilo
1. Clicca il tuo avatar in navbar
2. Seleziona **"Profilo"**

### Editing Profilo
1. Clicca **"Modifica profilo"**
2. Modifica:
   - **Username**: Il tuo nome utente pubblico
   - **Bio**: Descrizione personale (max 500 caratteri consigliato)

3. Clicca **"Salva"** per confermare
4. Clicca **"Annulla"** per scartare le modifiche

### I Tuoi Articoli
- La sezione "Articoli" mostra tutti i tuoi contenuti
- Se visualizzi il profilo di un altro utente, vedrai solo articoli pubblicati
- Se è il tuo profilo, vedrai anche le bozze

## 🌓 Dark Mode

### Attivare Dark Mode
1. Clicca l'icona sole/luna in alto a destra
2. La modalità si applica automaticamente
3. La preferenza viene salvata localmente

### Design Responsive
L'applicazione è ottimizzata per:
- **Desktop**: 3 colonne di articoli
- **Tablet**: 2 colonne di articoli
- **Mobile**: 1 colonna articoli

## 🔒 Sicurezza e Privacy

### I Tuoi Dati
- Password non sono mai memorizzate in questo sito
- L'autenticazione è gestita da provider sicuri (Google/GitHub)
- I tuoi articoli sono privati finché non li pubblichi

### RLS (Row Level Security)
- Solo tu puoi modificare il tuo profilo
- Solo tu puoi modificare/eliminare i tuoi articoli
- Chiunque può leggere articoli pubblicati
- I like sono visibili solo su articoli pubblicati

## ⚠️ Troubleshooting

### "Non riesco a fare il login"
- Verifica di avere una connessione internet
- Disabilita i popup blocker del browser
- Prova un browser diverso

### "Errore nel caricamento dell'immagine"
- Verifica che l'immagine sia JPG, PNG o WebP
- La dimensione deve essere < 5MB consigliato
- Riprova il caricamento

### "Il mio articolo non appare"
- Se è una bozza, non sarà visibile pubblicamente
- Clicca "Pubblica" per renderlo visibile
- Potrebbe necessitare di un refresh pagina

### "Non riesco a modificare l'articolo"
- Solo l'autore può modificare un articolo
- Se non lo hai scritto, non potrai modificarlo
- Se è una bozza, dovrai prima accedere

## 💡 Tips & Best Practices

### Per Articoli Migliori
1. **Titolo**: Mantieni conciso ma descrittivo
2. **Copertina**: Usa un'immagine di alta qualità
3. **Descrizione**: Incuriosisci il lettore
4. **Tag**: Usa 3-5 tag rilevanti
5. **Contenuto**: Dividi in paragrafi leggibili
6. **Formattazione**: Usa headings e blockquotes per struttura

### Engagement
- Scrivi regolarmente per costruire un'audience
- Rispondi ai commenti dei lettori (futura funzione)
- Usa tag popolar i per raggiungere più persone
- Condividi sui social media
